# dsci551-project

## Cockroach Cloud Setup

Following CockroachDB documentation: https://www.cockroachlabs.com/docs/stable/connect-to-the-database?filters=python

1. Download the valid CA certificate.

2. Run the command to export DATABASE_URL in the form of:

`export DATABASE_URL="postgresql://{username}:{password}@{host}:{port}/{database}?sslmode=verify-full"`.

DSCI 551 instructors: please find in the final report the exact commands to run (verbatim) which include the pre-setup certificate and connection string.

## Python Setup

Navigate to the dsci551-project directory.

In terminal run all shell commands in order:

`python3 -m venv env`

`source env/bin/activate`

`pip3 install -r requirements.txt`

## Running

(Run `source env/bin/activate` for each tab)

In the first terminal tab run: `python3 server.py`

In another terminal tab run: `python3 drone.py`

## Dataset

All data is generated by `drone.py` automatically as part of the simulation.

In the `drone.py` script, the initialization process first clears existing data in database, and then generates random geographic attributes, and creates new entities via calling RESTful APIs.

1. Database Initialization

Before any data is created, the script calls `ResetTables` which sends requests to the server to drop any existing drones and warehouses tables and re-initialize the schema, to ensure the simulation starts with a consistent and clean state.

2. Warehouse Generation and Loading

The `InitializeWarehouses` function creates a set of static warehouse entities (e.g., "SFO", "ORD", "LGA").

Generation: For each warehouse, the script generates a random location using `GenerateRandomLocation`.

Loading: The script calls `Register` method on the warehouse object. This sends a POST request to the `/register_warehouse` endpoint with the name and geographic coordinates. The server saves this to the database and returns a unique UUID, which the script then stores locally to identify the warehouse in future operations.

3. Drone Generation and Loading

The `InitializeDrones` function creates a fleet of drones.

Generation: Each drone is initialized with a generic name (e.g., `drone_0`) and a random starting position on the global map.

Loading: Similar to warehouses, each drone calls its `Register` method, sending a POST request to `/register_drone`. Once registered, the script calls `GetDroneState` to pull server-side data into the local Python `Drone` object.
